# River King Valley RPG 🎣

Jogo de RPG e Pesca estilo retrô (Game Boy) desenvolvido com **Svelte** e **Tailwind CSS**, modularizado em componentes organizados e de fácil manutenção.

## ✨ Recursos

- **Ciclo de Tempo e Estações**: Dias, horas, primaveras/verões/outonos/invernos e clima variável.
- **Vila Viva e NPCs**: Capitão Thomas, Mestre Gema (Marceneiro), Ana (Cozinheira) e Velho Joe com rotinas diárias e visitas à taverna.
- **Sistema de Pesca & Minigame**: Mira de distância, sombras de aproximação, puxada rápida e mecânica de tensão na linha.
- **Mais de 70 Espécies & Tesouros**: Peixes de rio, mar, criaturas de rede, itens de lixo e relíquias para o museu.
- **Catálogo & Pokédex de Peixes**: Registro de capturas, recordes de peso e peixes lendários/brilhantes (✨).
- **Construções & Melhorias**: Píer, docas, barco para alto-mar e aquário municipal.
- **Sistema de Salvamento**: Salva automaticamente no LocalStorage.

## 🚀 Como Executar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Para gerar a build de produção:
   ```bash
   npm run build
   ```
